# Open Resume Builder

I built this project out of frustration with exploitative resume builder sites that lock basic features behind paywalls. 

While it’s still a work in progress, the goal is simple: to help unemployed individuals and early-career professionals build a clean resume and get to the starting line without being charged.

## The future of this project
- Add multi-language support.
- Expand template options and formatting tools.
- General UI/UX improvements.

*Feedback and contributions are always welcome!*
